# Screenshots

The main README uses these four files. The versions here were taken on Linux; replace them
with screenshots from your own computer, using **exactly the same file names**, and the
README will pick them up automatically.

| File | What to show | How to take it |
|---|---|---|
| `main-window.png` | The whole window with an attractive shape, e.g. **Decahedron** (length / width ≈ 1.0) or **Octahedron** with *t* = 1/3, **Shape** tab open | Window only: Windows `Alt+PrintScreen`, or Snipping Tool › Window; macOS `Cmd+Shift+4`, then `Space`, then click the window |
| `display-tab.png` | The right-hand panel with the **Display** tab open | Snipping Tool › Rectangle (Windows) or `Cmd+Shift+4` and drag (macOS) around the panel |
| `save-dialog.png` | The **Save Image** dialog with *Transparent background* ticked | Open File › Save Image…, then take a window screenshot of the dialog |
| `transparent-preview.png` | The picture area with *Transparent background* ticked (checkerboard visible) | Rectangle screenshot of the picture area |

Tips:

- Use a window about 1100 × 700 px so the text stays readable on GitHub.
- Save as PNG. Keep each file under about 1 MB.
- On macOS, hold `Option` while clicking a window screenshot to leave out the drop shadow.
- Optional extra: `taskbar.png`, showing the app's own icon in the Windows taskbar or macOS Dock.
  If you add it, also add a line to the README to display it.
